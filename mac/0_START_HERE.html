AI秘書 セットアップガイド

macOS版 ／ プログラミングの知識は要りません

LINEに 「明日10時に歯医者」 と送るだけで Googleカレンダーに登録され、毎朝8時に今日の予定がLINEに届く、自分専用の秘書アプリです。

このガイドの通りに上から順にやれば動きます。コードを書く場面はありません。やることは「アカウントを作る」「表示された文字列をコピーする」「ファイルをダブルクリックする」の3種類だけです。

所要時間の目安

1〜2時間。半分は「アカウントを作って、届いたメールを確認する」待ち時間です。途中で中断してもOK。次に開いたところから再開できます。

この先の流れ

  1. 先に知っておくこと（費用・条件）
  2. LINEの「AI秘書」アカウントを作る
  3. Googleカレンダーを使えるようにする
  4. Gemini（AI）の鍵を取る
  5. ngrok（外から繋ぐ道具）を用意する
  6. フォルダを置く
  7. 1_setup.command を実行
  8. 2_google_auth.command を実行
  9. 3_start.command を実行
  10. 動作テストと朝の通知の設定
  11. 使い方（送れる文章の例）
  12. 毎日の運用で大事なこと
  13. 困ったとき
  14. やめたいとき

毎朝 8:00 → Macが自動でカレンダーを見て、今日の予定をLINEに送る

つまりあなたのMacがサーバーになります。ここが一番大事な性質で、次の制約に直結します。

最重要：Macの電源が入っていないと受け付けません

Macがシャットダウン中・スリープ中は、LINEに送っても登録されず、届かなかったメッセージは後から再送もされません（LINE側の仕様）。

対策は 「毎日の運用で大事なこと」 に書いてあります。MacBook をふたを閉じて持ち歩く使い方の人は、先にそこを読んでください。

必要なもの

  • macOS 12 以降の Mac（なるべく電源を入れっぱなしにできるもの）
  • インターネット接続
  • 普段使っている LINEアカウント（スマホのもの）
  • 普段使っている Googleアカウント（予定を入れたいカレンダーのもの）
  • メールアドレス（アカウント登録の確認用）

かかるお金

サービス料金
LINE Messaging API無料（無料プランは月200通まで。ただしあなたの送信への返信は通数に数えられません。数えられるのは朝の自動通知だけなので、実際は月30通ほどで収まります）
Googleカレンダー API無料
Gemini API個人利用ならほぼ無料〜月数十円。1回の解析が0.03円程度
ngrok無料（固定URL 1つまで無料）
クレジットカードについて

Gemini の設定の途中で、カード登録を求められることがあります。無料枠の範囲なら請求は発生しませんが、不安なら STEP 3 の「使いすぎ防止の上限」を必ず設定してください。上限を入れておけば、それ以上は課金されずに止まります。

STEP 1LINEの「AI秘書」アカウントを作る

普段のLINEとは別に、自分専用の公式アカウントを作ります。友だち追加すると、トーク画面が秘書との会話になります。

1-1. LINE公式アカウントを作る

  1. https://manager.line.biz/ を開く
  2. 「LINEアカウントで登録」→ 普段のLINEでログイン（QRコードか、メール＋パスワード）
  3. 「アカウントを作成」で入力：
    • アカウント名（必須）：AI秘書 — スマホのLINEの友だちリスト・トーク画面に出る名前です
    • メールアドレス（必須）：自分のメールアドレス（普段のGmailでOK）
    • 会社・事業者の所在国・地域（必須）：日本 のまま
    • 会社・事業者名：空欄でOK（● が付いていない項目は任意）
    • 業種（必須）：大業種「個人」→ 小業種「個人（その他）」

    会社名や業種はLINE側の分類のために聞かれているだけで、動作には影響しません。個人利用なので深く考えず埋めて大丈夫です。

  4. 作成すると「LINE Official Account Manager」の管理画面に入ります

1-2. Messaging API を有効にする

これが「プログラムから操作できるようにする」スイッチです。

  1. 管理画面の右上 「設定」 をクリック
  2. 左メニューの 「Messaging API」 をクリック
  3. 「Messaging APIを利用する」 ボタンをクリック
  4. プロバイダーを聞かれます。「プロバイダーを作成」を選び、自分の名前などを入力（何でもOK。あとから変えられません）
  5. そのまま進めて「同意する」→ 完了
プロバイダーって何？

「このアプリを作った人」の名前です。自分ひとりで使うので、深く考えず自分の名前で大丈夫です。

1-3. 自動返信をオフにする（重要）

初期状態では「お問い合わせありがとうございます」のような定型文が自動で返ってしまい、秘書の返事とぶつかります。切ります。

  1. 同じ「設定」画面の左メニュー 「応答設定」 をクリック
  2. 応答モード → 「Bot」 を選ぶ
  3. 応答メッセージ → オフ
  4. あいさつメッセージ → オフ推奨（お好みで）
  5. Webhook → オン ← これを忘れると何も動きません
  6. 「保存」
「Webhook URL を入力してください」と言われたら → 空欄のままでOK

そのURLは STEP 4 で ngrok の固定ドメインを取って初めて決まるので、今はまだ存在しません。空欄で保存できるならそのまま保存、URLが無いと保存できないならこの設定はいったん飛ばして STEP 2 へ進んでください。

URLを手で打つ場面はありません。 STEP 8 の 3_start.command が LINE に自動で登録します。そのとき「Webhookの利用がオフです」と警告が出たら、この画面に戻ってトグルをオンにするだけです。

1-4. 鍵を2つコピーする

ここで使うのは「別のサイト」です

いままで作業していた LINE Official Account Manager(manager.line.biz) ではなく、 LINE Developers(developers.line.biz) に移動します。

紛らわしいのですが、管理画面の「設定 → Messaging API」にも Channel secret は表示されます（そちらをコピーしてもOK）。 ただしチャネルアクセストークンは管理画面には存在しません。必ず LINE Developers 側で発行します。

近道：管理画面の「設定 → Messaging API」の下にある 「その他の設定はLINE Developersコンソールから行えます」のリンクを押すと、そのチャネルの画面へ直接飛べます。

  1. https://developers.line.biz/console/ を開く（さっきと違うサイトです）
  2. 同じLINEアカウントでログイン → さっき作ったプロバイダーをクリック → AI秘書 のチャネルをクリック
  3. 上のタブを切り替えて、2つの文字列をテキストエディットにコピー：
タブ項目メモに書く名前
チャネル基本設定チャネルシークレット②シークレット
Messaging API設定チャネルアクセストークン（長期）①アクセストークン

チャネルアクセストークンは「Messaging API設定」タブの一番下にあります。ページを最後までスクロールしてください。空欄なら 「発行」 ボタンを押すと出ます。とても長い文字列（200文字以上）なので、末尾まで全部コピーしてください。

この2つは他人に見せないこと

これはあなたのLINE公式アカウントを操作できる鍵です。SNSやチャットに貼らないでください。

1-5. スマホで友だち追加する

「Messaging API設定」タブにQRコードがあります。スマホのLINEで読み取って友だち追加してください。これがあなたと秘書のトーク画面になります。

STEP 2Googleカレンダーを使えるようにする

プログラムがあなたのカレンダーを読み書きできるよう、許可証を作ります。ここが一番画面が多い工程ですが、やることは単純です。

2-1. プロジェクトを作る

  1. https://console.cloud.google.com/ を開く（予定を入れたいGoogleアカウントでログイン）
  2. 初回は利用規約への同意を求められます。同意して進む
  3. 画面上部の 「プロジェクトを選択」 → 「新しいプロジェクト」
  4. プロジェクト名：AI-hisho → 「作成」
  5. 作成後、上部でそのプロジェクトが選ばれていることを確認（ここを間違えると後の作業が全部空振りします）
Google Cloud では日本語の名前が使えません

プロジェクト名に AI秘書 と入れると「名前に無効な文字が使用されています」と怒られます。 使えるのは英数字・ハイフン・スペース・'・! だけです。

プロジェクト名はただのラベルで動作には一切影響しません。AI-hisho のようなASCII名にしてください。 下に出る「プロジェクトID」は自動生成のままでOKです。

このあとの STEP 2-4 のクライアント名も同様に AI-hisho desktop としてください。

「My First Project」のまま進んでしまっても直さなくてOK

気づいたら画面上部が My First Project になっていた、ということがあります。 作り直す必要はありません。プロジェクト名は動作に一切関係ないからです。

大事なのは 2-2・2-3・2-4 を全部おなじプロジェクトでやることだけ。 画面上部の名前がずっと同じであることを確認しながら進めてください。

途中で切り替えると「APIは有効なのに認証が通らない」という原因の分かりにくい失敗になります。混ぜないことだけが重要です。

2-2. カレンダーAPIを有効にする

  1. 左上の ☰ メニュー → 「APIとサービス」 → 「ライブラリ」
  2. 検索欄に Google Calendar API と入力
  3. 出てきた「Google Calendar API」をクリック → 「有効にする」

2-3. 同意画面を作り、「本番環境」にする

ここを飛ばすと1週間で壊れます

「テスト」状態のままだと許可証が7日で自動的に失効し、毎週エラーになります。必ず「本番環境」にしてください。

  1. 左メニュー 「APIとサービス」 → 「OAuth同意画面」（新しい画面では 「Google Auth Platform」→「ブランディング」）
  2. まだ作っていなければ「開始」から作成：
    • アプリ名：AI秘書
    • ユーザーサポートメール：自分のアドレス
    • 対象：「外部」を選ぶ
    • 連絡先メール：自分のアドレス
  3. 作成後、左メニュー 「対象」（または「OAuth同意画面」）を開く
  4. 公開ステータスが「テスト」なら 「アプリを公開」 ボタンを押す → 確認
  5. 「本番環境」になればOK
審査は要りません

自分のカレンダーを読むだけなので、Googleの審査なしで「本番環境」にできます。「未確認のアプリ」という警告は出ますが、自分で作ったものなので問題ありません。

2-4. 許可証（credentials.json）をダウンロードする

  1. 左メニュー 「クライアント」（または「認証情報」）
  2. 「＋ クライアントを作成」（または「＋ 認証情報を作成」→「OAuth クライアント ID」）
  3. アプリケーションの種類：「デスクトップアプリ」 ← ここを間違えないでください
  4. 名前：AI-hisho desktop → 「作成」
  5. 出てきたダイアログの 「JSONをダウンロード」 をクリック

ダウンロードされた client_secret_xxxxx.json はあとで使います。ダウンロードフォルダに置いたままでOK。STEP 5 で名前を変えて移動します。

STEP 3Gemini（AI）の鍵を取る

「明日10時に歯医者」という日本語を読み取る担当です。

  1. https://aistudio.google.com/apikey を開く（STEP 2 と同じGoogleアカウントで）
  2. 「APIキーを作成」 をクリック
  3. プロジェクトを聞かれたら、STEP 2 で作った AI-hisho を選ぶ
  4. 出てきた AIza... で始まる文字列をテキストエディットにコピー（③Geminiキー）
使いすぎ防止の上限を入れておく

もし課金設定になっている場合は、https://aistudio.google.com/usage で月の上限（例：1,000円）を設定しておくと安心です。無料枠のままなら設定は不要ですが、入れておいて損はありません。

STEP 4ngrok（外から繋ぐ道具）を用意する

ngrok は、あなたのMacの中で動くプログラムにインターネットから届くURLを1本くれる道具です。ルーターの設定変更などは要りません。自宅Wi-Fiのままで動きます。

4-1. アカウントを作る

  1. https://dashboard.ngrok.com/signup を開く
  2. メールアドレス、または Google/GitHubアカウントで登録
  3. 届いたメールのリンクをクリックして認証

4-2. Authtoken をコピーする

  1. ログイン後、左メニュー 「Your Authtoken」（または Getting Started → Your Authtoken）
  2. 表示された文字列をテキストエディットにコピー（④Authtoken）

4-3. 固定ドメインをもらう（無料で1つ）

これを取らないと毎回URLが変わります

固定ドメインを使わないと、Macを再起動するたびにURLが変わり、そのつどLINE側の設定をやり直すことになります。必ず取ってください（無料です）。

  1. 左メニュー 「Domains」（Universal Gateway の下）
  2. 「+ Create Domain」（または「+ New Domain」）をクリック
  3. gentle-cat-4821.ngrok-free.dev のような名前が自動で割り当てられます
  4. この文字列をテキストエディットにコピー（④ドメイン）
コピーのしかた

https:// や末尾の / が付いていても大丈夫です。あとで自動的に取り除かれます。

STEP 5フォルダを置く

5-1. 展開する

  1. 受け取った ai-hisho-mac.zip をダブルクリックすると、同じ場所に ai-hisho フォルダができます
  2. そのフォルダを 書類（Documents）フォルダ など、分かりやすい場所に移動してください
置き場所はどこでも構いません

Windows版と違って場所は固定されていません。あとで移動しても、3_start.command を実行し直せば追随します。

ただし ダウンロードフォルダに置きっぱなしにしないでください。整理のつもりで消してしまう事故が起きます。

5-2. Googleの許可証を置く

STEP 2 でダウンロードした JSON ファイルの名前を credentials.json に変えて、ai-hisho フォルダの直下（1_setup.command と同じ場所）に置いてください。

拡張子が隠れているとき

Finder で名前が credentials としか見えない場合、拡張子が隠れているだけで正しく置けています。心配なら Finder メニューの「設定」→「詳細」→「すべてのファイル名拡張子を表示」にチェックを入れると確認できます。

STEP 61_setup.command を実行

最初の1回だけ、開き方に手順が要ります（Macの安全機能）

インターネット経由で受け取ったファイルは、macOS が念のため実行をブロックします。ダブルクリックではなく、次のようにして開いてください。

  1. 1_setup.command を 右クリック（またはControlキーを押しながらクリック）
  2. メニューから 「開く」 を選ぶ
  3. 「開発元を確認できません」と出たら、もう一度 「開く」 をクリック

それでも開けない場合は、アップルメニュー →「システム設定」→「プライバシーとセキュリティ」 を開き、下の方に出ている「"1_setup.command"は開発元を確認できないため……」の横の 「このまま開く」 を押してください。

2回目以降と、他のファイル（2_・3_・4_など）は普通のダブルクリックで開きます。最初の1本が、残り全部のブロックをまとめて解除するようになっています。

ターミナルという黒い（または白い）文字だけの画面が開き、上から順に進みます。文字が流れていくのは正常です。

聞かれること

STEP 1〜4 で控えた値を、順番に貼り付けます（command+V で貼り付け、Enter で次へ）。

  1. LINE のチャネルアクセストークン
  2. LINE のチャネルシークレット
  3. Gemini API キー
  4. ngrok の固定ドメイン
  5. ngrok の Authtoken

初回はパッケージのダウンロードで数分かかります。「1/4 完了」と出れば成功です。

「使える Python が見つかりませんでした」と言われた

ターミナルを開いて（command+space →「ターミナル」と入力）、次の1行を実行してください。Apple 純正の開発ツールが入り、Python が使えるようになります。

xcode-select --install

画面の指示に従って進め（10〜20分かかります）、終わったら 1_setup.command をやり直してください。

Gemini のキーが「使えません」と出た

先に進めますが、そのままだと LINE に送っても予定を読み取れません。画面に出ている対処をそのまま試してください。特に、キーが AQ. で始まる場合は従来形式（AIza…）を作り直すと通ることが多いです。

STEP 72_google_auth.command を実行

ダブルクリックすると、Enter を押したあとにブラウザが開きます。

  1. 自分の Google アカウントを選ぶ
  2. 「このアプリは Google で確認されていません」→ 左下【詳細】→【（アプリ名）に移動】
  3. 「カレンダーの予定の表示と編集」にチェック →【続行】

「許可が取れました」と出れば完了です。自分で作ったアプリなので、この警告が出るのが正常です。

STEP 83_start.command を実行

これで次の3つがまとめて行われます。

  • Mac にログインすると自動で立ち上がるように登録
  • 毎朝8時の通知を登録
  • LINE 側の「送り先URL」を自動で設定

「起動しました」と出れば完成です。

「ポート 5555 を別のプログラムが使っています」と出た

他のアプリが同じ番号を使っています。フォルダ内の .env をテキストエディットで開き、WEBHOOK_PORT=5555 を WEBHOOK_PORT=5556 に書き換えて保存し、3_start.command をやり直してください。

STEP 9動作テストと朝の通知の設定

9-1. まず1通送ってみる

LINE の「AI秘書」に 「明日10時にテスト」 と送ってください。✅ 登録しました と返ってくれば成功です。Googleカレンダーにも入っています。

9-2. 朝の通知の宛先を設定する

1通送ったあとで 4_set_user_id.command をダブルクリックしてください。送信ログからあなたの ID を自動で読み取って設定します。

9-3. 通知を試す

test_notify.command で、朝の通知をその場で試せます。今日の予定が0件の日は、あえて何も送りません（仕様）。

9-4. 全部できたか確認

status.command をダブルクリックして、項目がすべて OK になっていれば完成です。

毎日の運用で大事なこと

Macがスリープしている間のメッセージは失われます

ふたを閉じている間・電源が落ちている間は、LINE に送っても受け取れません。LINE は届かなかった分を送り直さないので、その間のメッセージは消えます。

朝8時の通知は、スリープで時刻を過ぎてもふたを開けたときにまとめて実行されるので比較的取りこぼしません。

対策：スリープしないようにする

電源につないでいる間だけスリープしない設定にできます。アップルメニュー →「システム設定」→「ロック画面」で、「電源アダプタ接続時にディスプレイがオフのときに自動でスリープさせない」をオンにしてください。

ふたを閉じても動かし続けたい場合は、外部ディスプレイか電源に接続した状態が必要です（Mac の仕様です）。

Macを再起動したあと

何もしなくて大丈夫です。ログインすると自動で立ち上がります。心配なら status.command で確認してください。

困ったとき

まず status.command を実行してください。どこで止まっているかが上から順に出ます。

LINEに送っても何も返ってこない
  1. status.command を実行して【失敗】の項目を見る
  2. 「繋がりません」→ 3_start.command を実行
  3. 「Webhookの利用: オフ」→ LINE Official Account Manager → 設定 → 応答設定 → Webhook をオン
  4. すべてOKなのに返らない → Mac がスリープしていた可能性。もう一度送ってみる
「⚠️ カレンダーに接続できません」と返ってくる

Googleの許可が切れています。返信に出ている手順（2_google_auth.command をダブルクリック）をそのまま実行してください。

朝の通知でも同じことが起きると、LINEに同じ警告が1日1回届きます（黙って通知が止まらないようにするためです）。

繰り返し起きるなら STEP 2-3 の「本番環境」になっていない可能性が高いです。テストのままだと7日で切れます。

「エラーが発生しました」と返ってくる

プログラムは動いていますが、途中で失敗しています。フォルダ内の logs/webhook.err.log をテキストエディットで開き、いちばん下を見てください。

  • 429 / RESOURCE_EXHAUSTED → Geminiの無料枠を使い切っています。時間をおくか、課金設定を確認
  • 401 / Invalid access token → LINEのアクセストークンが違うか、再発行されています。1_setup.command で入れ直す
変な予定が登録される・日付がずれる

AIの読み取り間違いです。もう少しはっきり書くと通ります（例：「明日」→「4/25」、「夕方」→「18時」）。

間違って登録されたものは ◯◯をキャンセル と送れば消せます。Googleカレンダーから直接消しても構いません。

朝8時に通知が来ない
  1. status.command の「1. 設定ファイル」で LINE_USER_ID が設定済みか確認。空なら 4_set_user_id.command
  2. 「7. 毎朝8時の通知」が「未登録」なら 3_start.command
  3. その日の予定が0件なら、そもそも送りません（仕様）
  4. 「⚠️ カレンダーに接続できません」が届いていたら 2_google_auth.command を実行
  5. test_notify.command で今すぐ試して切り分ける
フォルダを移動したら動かなくなった

3_start.command を実行し直してください。今の場所で登録し直されます。

status.command の「3. 常駐の登録と稼働」に「登録されている場所と今の場所が違います」と出ていれば、これが原因です。

ngrokのURLが変わってしまった / 外から繋がらない

固定ドメインを使っているので、通常は変わりません。フォルダ内の logs/ngrok.log の末尾を確認してください。

  • ERR_NGROK_108（同時接続数の上限）→ 別の場所でngrokが動いています。stop.command のあと 3_start.command
  • authentication failed → Authtokenが未設定。1_setup.command をやり直す
設定した鍵を入れ直したい

1_setup.command をもう一度実行してください。今の値が表示され、Enter だけ押せばそのまま、入力すれば上書きされます。終わったら 3_start.command で反映します。

「開発元を確認できないため開けません」が何度も出る

ターミナルを開いて次の1行を実行すると、フォルダ全体のブロックが外れます（~/Documents/ai-hisho の部分は実際の置き場所に合わせてください）。

xattr -dr com.apple.quarantine ~/Documents/ai-hisho

やめたいとき

一時的に止める

stop.command をダブルクリック。3_start.command でいつでも戻せます。

自動起動をやめる

uninstall.command をダブルクリック。設定やログは残るので、また使いたくなったら 3_start.command で復活します。

完全に消す

uninstall.command を実行したあと、ai-hisho フォルダごとゴミ箱に入れてください。LINE公式アカウントやGoogleの設定も消したい場合は、それぞれのサイトで削除します。
