AI秘書 セットアップガイド

Windows版 ／ プログラミングの知識は要りません

LINEに 「明日10時に歯医者」 と送るだけで Googleカレンダーに登録され、毎朝8時に今日の予定がLINEに届く、自分専用の秘書アプリです。

このガイドの通りに上から順にやれば動きます。コードを書く場面はありません。やることは「アカウントを作る」「表示された文字列をコピーする」「ファイルをダブルクリックする」の3種類だけです。

すでに使っている人へ（更新のしかた）

前の版を入れてある場合、STEP 1〜9をやり直す必要はありません。次の3つだけで新しい版に入れ替わります。

  1. stop.bat をダブルクリック（動いているものを止める）
  2. 新しい ZIP を展開し、中身を C:\ai-hisho に上書きコピー（「置き換える」を選ぶ）
  3. 3_start.bat をダブルクリック

設定（.env）・Googleの許可（token.json）・記録（schedule.db）は ZIP に入っていないので、上書きしても消えません。1_setup.bat や 2_google_auth.bat をやり直す必要もありません。

所要時間の目安

1〜2時間。半分は「アカウントを作って、届いたメールを確認する」待ち時間です。途中で中断してもOK。次に開いたところから再開できます。

この先の流れ

  1. 先に知っておくこと（費用・条件）
  2. LINEの「AI秘書」アカウントを作る
  3. Googleカレンダーを使えるようにする
  4. Gemini（AI）の鍵を取る
  5. ngrok（外から繋ぐ道具）を用意する
  6. フォルダを置く
  7. 1_setup.bat を実行
  8. 2_google_auth.bat を実行
  9. 3_start.bat を実行
  10. 動作テストと朝の通知の設定
  11. 使い方（送れる文章の例）
  12. 毎日の運用で大事なこと
  13. 困ったとき
  14. やめたいとき

つまりあなたのPCがサーバーになります。ここが一番大事な性質で、次の制約に直結します。

最重要：PCの電源が入っていないと受け付けません

PCがシャットダウン中・スリープ中は、LINEに送っても登録されず、届かなかったメッセージは後から再送もされません（LINE側の仕様）。

対策は 「毎日の運用で大事なこと」 に書いてあります。ノートPCを開いたり閉じたりして使う人は、先にそこを読んでください。

必要なもの

  • インターネット接続
  • 普段使っている LINEアカウント（スマホのもの）
  • 普段使っている Googleアカウント（予定を入れたいカレンダーのもの）
  • メールアドレス（アカウント登録の確認用）

かかるお金

STEP 1LINEの「AI秘書」アカウントを作る

普段のLINEとは別に、自分専用の公式アカウントを作ります。友だち追加すると、トーク画面が秘書との会話になります。

1-1. LINE公式アカウントを作る

  1. https://manager.line.biz/ を開く
  2. 「LINEアカウントで登録」→ 普段のLINEでログイン（QRコードか、メール＋パスワード）
  3. 「アカウントを作成」で入力：
    • アカウント名（必須）：AI秘書 — スマホのLINEの友だちリスト・トーク画面に出る名前です
    • メールアドレス（必須）：自分のメールアドレス（普段のGmailでOK）
    • 会社・事業者の所在国・地域（必須）：日本 のまま
    • 会社・事業者名：空欄でOK（● が付いていない項目は任意）
    • 業種（必須）：大業種「個人」→ 小業種「個人（その他）」

    会社名や業種はLINE側の分類のために聞かれているだけで、動作には影響しません。個人利用なので深く考えず埋めて大丈夫です。

  4. 作成すると「LINE Official Account Manager」の管理画面に入ります

1-2. Messaging API を有効にする

これが「プログラムから操作できるようにする」スイッチです。

  1. 管理画面の右上 「設定」 をクリック
  2. 左メニューの 「Messaging API」 をクリック
  3. 「Messaging APIを利用する」 ボタンをクリック
  4. プロバイダーを聞かれます。「プロバイダーを作成」を選び、自分の名前などを入力（何でもOK。あとから変えられません）
  5. そのまま進めて「同意する」→ 完了
プロバイダーって何？

「このアプリを作った人」の名前です。自分ひとりで使うので、深く考えず自分の名前で大丈夫です。

1-3. 自動返信をオフにする（重要）

初期状態では「お問い合わせありがとうございます」のような定型文が自動で返ってしまい、秘書の返事とぶつかります。切ります。

  1. 同じ「設定」画面の左メニュー 「応答設定」 をクリック
  2. 応答モード → 「Bot」 を選ぶ
  3. 応答メッセージ → オフ
  4. あいさつメッセージ → オフ推奨（お好みで）
  5. Webhook → オン ← これを忘れると何も動きません
  6. 「保存」
「Webhook URL を入力してください」と言われたら → 空欄のままでOK

そのURLは STEP 4 で ngrok の固定ドメインを取って初めて決まるので、今はまだ存在しません。空欄で保存できるならそのまま保存、URLが無いと保存できないならこの設定はいったん飛ばして STEP 2 へ進んでください。

URLを手で打つ場面はありません。 STEP 8 の 3_start.bat が LINE に自動で登録します。そのとき「Webhookの利用がオフです」と警告が出たら、この画面に戻ってトグルをオンにするだけです。

1-4. 鍵を2つコピーする

ここで使うのは「別のサイト」です

いままで作業していた LINE Official Account Manager(manager.line.biz) ではなく、 LINE Developers(developers.line.biz) に移動します。

紛らわしいのですが、管理画面の「設定 → Messaging API」にも Channel secret は表示されます（そちらをコピーしてもOK）。 ただしチャネルアクセストークンは管理画面には存在しません。必ず LINE Developers 側で発行します。

近道：管理画面の「設定 → Messaging API」の下にある 「その他の設定はLINE Developersコンソールから行えます」のリンクを押すと、そのチャネルの画面へ直接飛べます。

  1. https://developers.line.biz/console/ を開く（さっきと違うサイトです）
  2. 同じLINEアカウントでログイン → さっき作ったプロバイダーをクリック → AI秘書 のチャネルをクリック
  3. 上のタブを切り替えて、2つの文字列をメモ帳にコピー：
タブ項目メモに書く名前
チャネル基本設定チャネルシークレット②シークレット
Messaging API設定チャネルアクセストークン（長期）①アクセストークン

チャネルアクセストークンは「Messaging API設定」タブの一番下にあります。ページを最後までスクロールしてください。空欄なら 「発行」 ボタンを押すと出ます。とても長い文字列（200文字以上）なので、末尾まで全部コピーしてください。

この2つは他人に見せないこと

これはあなたのLINE公式アカウントを操作できる鍵です。SNSやチャットに貼らないでください。

1-5. スマホで友だち追加する

「Messaging API設定」タブにQRコードがあります。スマホのLINEで読み取って友だち追加してください。これがあなたと秘書のトーク画面になります。

STEP 2Googleカレンダーを使えるようにする

プログラムがあなたのカレンダーを読み書きできるよう、許可証を作ります。ここが一番画面が多い工程ですが、やることは単純です。

2-1. プロジェクトを作る

  1. https://console.cloud.google.com/ を開く（予定を入れたいGoogleアカウントでログイン）
  2. 初回は利用規約への同意を求められます。同意して進む
  3. 画面上部の 「プロジェクトを選択」 → 「新しいプロジェクト」
  4. プロジェクト名：AI-hisho → 「作成」
  5. 作成後、上部でそのプロジェクトが選ばれていることを確認（ここを間違えると後の作業が全部空振りします）
Google Cloud では日本語の名前が使えません

プロジェクト名に AI秘書 と入れると「名前に無効な文字が使用されています」と怒られます。 使えるのは英数字・ハイフン・スペース・'・! だけです。

プロジェクト名はただのラベルで動作には一切影響しません。AI-hisho のようなASCII名にしてください。 下に出る「プロジェクトID」は自動生成のままでOKです。

このあとの STEP 2-4 のクライアント名も同様に AI-hisho desktop としてください。

「My First Project」のまま進んでしまっても直さなくてOK

気づいたら画面上部が My First Project になっていた、ということがあります。 作り直す必要はありません。プロジェクト名は動作に一切関係ないからです。

大事なのは 2-2・2-3・2-4 を全部おなじプロジェクトでやることだけ。 画面上部の名前がずっと同じであることを確認しながら進めてください。

途中で切り替えると「APIは有効なのに認証が通らない」という原因の分かりにくい失敗になります。混ぜないことだけが重要です。

2-2. カレンダーAPIを有効にする

  1. 左上の ☰ メニュー → 「APIとサービス」 → 「ライブラリ」
  2. 検索欄に Google Calendar API と入力
  3. 出てきた「Google Calendar API」をクリック → 「有効にする」

2-3. 同意画面を作り、「本番環境」にする

ここを飛ばすと1週間で壊れます

「テスト」状態のままだと許可証が7日で自動的に失効し、毎週エラーになります。必ず「本番環境」にしてください。

  1. 左メニュー 「APIとサービス」 → 「OAuth同意画面」（新しい画面では 「Google Auth Platform」→「ブランディング」）
  2. まだ作っていなければ「開始」から作成：
    • アプリ名：AI秘書
    • ユーザーサポートメール：自分のアドレス
    • 対象：「外部」を選ぶ
    • 連絡先メール：自分のアドレス
  3. 作成後、左メニュー 「対象」（または「OAuth同意画面」）を開く
  4. 公開ステータスが「テスト」なら 「アプリを公開」 ボタンを押す → 確認
  5. 「本番環境」になればOK
審査は要りません

自分のカレンダーを読むだけなので、Googleの審査なしで「本番環境」にできます。「未確認のアプリ」という警告は出ますが、自分で作ったものなので問題ありません。

2-4. 許可証（credentials.json）をダウンロードする

  1. 左メニュー 「クライアント」（または「認証情報」）
  2. 「＋ クライアントを作成」（または「＋ 認証情報を作成」→「OAuth クライアント ID」）
  3. アプリケーションの種類：「デスクトップアプリ」 ← ここを間違えないでください
  4. 名前：AI-hisho desktop → 「作成」
  5. 出てきたダイアログの 「JSONをダウンロード」 をクリック

ダウンロードされた client_secret_xxxxx.json はあとで使います。ダウンロードフォルダに置いたままでOK。STEP 5 で名前を変えて移動します。

STEP 3Gemini（AI）の鍵を取る

「明日10時に歯医者」という日本語を読み取る担当です。

  1. https://aistudio.google.com/apikey を開く（STEP 2 と同じGoogleアカウントで）
  2. 「APIキーを作成」 をクリック
  3. プロジェクトを聞かれたら、STEP 2 で作った AI-hisho を選ぶ
  4. 出てきた AIza... で始まる文字列をメモ帳にコピー（③Geminiキー）
使いすぎ防止の上限を入れておく

もし課金設定になっている場合は、https://aistudio.google.com/usage で月の上限（例：1,000円）を設定しておくと安心です。無料枠のままなら設定は不要ですが、入れておいて損はありません。

STEP 4ngrok（外から繋ぐ道具）を用意する

ngrok は、あなたのPCの中で動くプログラムにインターネットから届くURLを1本くれる道具です。ルーターの設定変更などは要りません。自宅Wi-Fiのままで動きます。

4-1. アカウントを作る

  1. https://dashboard.ngrok.com/signup を開く
  2. メールアドレス、または Google/GitHubアカウントで登録
  3. 届いたメールのリンクをクリックして認証

4-2. Authtoken をコピーする

  1. ログイン後、左メニュー 「Your Authtoken」（または Getting Started → Your Authtoken）
  2. 表示された文字列をメモ帳にコピー（④Authtoken）

4-3. 固定ドメインをもらう（無料で1つ）

これを取らないと毎回URLが変わります

固定ドメインを使わないと、PCを再起動するたびにURLが変わり、そのつどLINE側の設定をやり直すことになります。必ず取ってください（無料です）。

  1. 左メニュー 「Domains」（Universal Gateway の下）
  2. 「+ Create Domain」（または「+ New Domain」）をクリック
  3. gentle-cat-4821.ngrok-free.dev のような名前が自動で割り当てられます
  4. この文字列をメモ帳にコピー（④ドメイン）
コピーのしかた

https:// や末尾の / が付いていても大丈夫です。あとで自動的に取り除かれます。

STEP 5フォルダを置く

5-1. 展開する

  1. 受け取ったZIPファイルを右クリック → 「すべて展開」
  2. 展開先を C:\ai-hisho に変更する（アドレス欄に直接この文字を打ち込む）
  3. 「展開」をクリック
OneDrive の中に置かないでください

Windowsでは「ダウンロード」「デスクトップ」「ドキュメント」が自動的に OneDrive の中になっていることがよくあります。アドレス欄に OneDrive と出ていたらそこは避けてください。理由は3つあります。

  • 鍵がクラウドに上がります。このあと作られる .env・credentials.json・token.json は、あなたのLINEとGoogleカレンダーを操作できる鍵そのものです
  • プログラムが勝手に消えます。OneDriveは使っていないファイルを「クラウドのみ」に追い出すため、動作中に本体が無くなった扱いになります
  • とても重くなります。このあと作られる作業用フォルダは数万ファイルあり、OneDriveが延々と同期しようとして、途中でエラーになることがあります
置き場所は C:\ai-hisho にしてください

フォルダ名に日本語やスペースが混ざると途中で謎のエラーが出ることがあります。C:\ai-hisho なら確実です。C:\ に置けないときは C:\Users\（自分の名前）\ai-hisho でも構いません（OneDriveの外であることが条件）。

展開後、C:\ai-hisho の中に 1_setup.bat が直接見えていれば正解です。C:\ai-hisho\ai-hisho\1_setup.bat のように二重になっていたら、内側のフォルダの中身を C:\ai-hisho に移動してください。

置き場所を間違えても、1_setup.bat を実行する前ならフォルダごと移動するだけで直ります。実行後に気づいた場合は、フォルダを移動したうえで 1_setup.bat からやり直してください。

5-2. Googleの許可証を置く

  1. STEP 2-4 でダウンロードした client_secret_xxxxx.json を C:\ai-hisho にコピー
  2. そのファイルの名前を credentials.json に変更する
拡張子が見えないとき

ファイル名を変えたのに credentials.json.json になってしまう場合があります。エクスプローラーの 「表示」→「表示」→「ファイル名拡張子」 にチェックを入れると、正しい名前が見えるようになります。

STEP 61_setup.bat を実行

C:\ai-hisho の中の 1_setup.bat をダブルクリックします。黒い画面が開いて、自動で進みます。

やってくれること：

  • Python（プログラムを動かす土台）を探す。無ければインストールを提案してくれます
  • 必要な部品をインターネットから取ってくる（数分かかります）
  • ngrok を自動でダウンロードする
  • メモ帳に控えた鍵の入力を求めてくる

聞かれること

順番に4つ聞かれます。メモ帳からコピーして、黒い画面で右クリックすると貼り付けられます（Ctrl+V でもOK）。貼り付けたら Enter。

聞かれるものメモの
LINE チャネルアクセストークン①
LINE チャネルシークレット②
Gemini API キー③
ngrok の固定ドメイン④ドメイン
ngrok Authtoken④Authtoken
最後に緑色で「1/3 完了」と出れば成功

黄色い【注意】や赤い【失敗】が出たら、そこに書かれた指示に従ってから 1_setup.bat をもう一度ダブルクリックしてください。何度実行しても壊れません。

「Pythonが見つかりません」と言われた

その場で「今すぐ自動でインストールしますか？」と聞かれるので y と入力してください。数分かかります。終わったら黒い画面を閉じて、1_setup.bat をもう一度ダブルクリック。

自動インストールができない場合は手動で：

  1. python.org から「Windows installer (64-bit)」をダウンロード
  2. インストーラの最初の画面で 「Add python.exe to PATH」にチェック（重要）
  3. 「Install Now」でインストール
  4. 1_setup.bat をもう一度実行
青い「WindowsによってPCが保護されました」が出た

「詳細情報」 をクリック → 「実行」 を押してください。ネットからダウンロードしたファイルに出る標準的な警告です。

STEP 72_google_auth.bat を実行

2_google_auth.bat をダブルクリック。Enter を押すとブラウザが開きます。

  1. 自分のGoogleアカウントを選ぶ
  2. 「このアプリは Google で確認されていません」 と出たら：
    • 左下の 「詳細」 をクリック
    • 「AI秘書（安全ではないページ）に移動」 をクリック
  3. 「カレンダーの予定の表示と編集」にチェック → 「続行」
  4. ブラウザに「認証フローが完了しました」と出たら閉じてOK
この警告は正常です

Googleの審査を受けていない個人アプリなので必ず出ます。作ったのは自分自身なので、そのまま進めて問題ありません。

黒い画面に 「2/3 完了」 と出れば成功です。

STEP 83_start.bat を実行

3_start.bat をダブルクリック。これで完成です。

やってくれること：

  • 秘書プログラムと ngrok を起動する
  • Windowsを起動するたび自動で立ち上がるように登録する
  • 毎朝8時の通知を登録する
  • LINE側のWebhook URLを自動で設定する（手作業不要）

最後に緑色で 「起動しました」 と出れば成功です。この黒い画面は閉じて構いません（プログラムは裏で動き続けます）。

「LINE側のWebhookの利用がオフです」と黄色で出たら

STEP 1-3 の設定が漏れています。LINE Official Account Manager → 設定 → 応答設定 → Webhook をオン → 保存。そのあと 3_start.bat をもう一度実行してください。

ファイアウォールの許可を聞かれた

「プライベートネットワーク」にチェックを入れて「アクセスを許可する」を押してください。（この構成では基本的に聞かれないはずですが、環境によっては出ます）

STEP 9動作テストと朝の通知の設定

9-1. まず1通送ってみる

スマホのLINEで AI秘書 のトークを開き、こう送ります：

明日10時にテスト

数秒で ✅ 登録しました と返ってくれば成功です。Googleカレンダーを開くと、明日の10時に「テスト」が入っています。

返事が来ないときは status.bat をダブルクリックしてください。どこで止まっているかを上から順に調べて教えてくれます。

9-2. 朝の通知の宛先を設定する

「毎朝8時にあなたへ送る」には、あなたが誰なのかをプログラムに教える必要があります。9-1で1通送ったあと、次を実行してください。

4_set_user_id.bat をダブルクリック。ログから自動で読み取って設定してくれます。

9-3. 通知を試す

test_notify.bat をダブルクリックすると、朝8時に流れるのと同じ通知が今すぐ届きます。

何も届かないとき

今日の予定が1件も無い日は、あえて何も送りません（毎朝「予定なし」と通知されると邪魔なため）。カレンダーに今日の予定を1つ入れてから試してください。

また1日1回しか送らない仕組みです。2回目を試したい場合は C:\ai-hisho\schedule.db を削除してから再実行してください。

9-4. 全部できたか確認

status.bat をダブルクリックして、7項目すべてが OK になっていれば完成です。

LINEに普通の日本語で送るだけです。決まった書き方はありません。

自動で届くもの

  • 毎朝 8:00：今日の予定（予定が無い日は送りません）
  • 月曜の朝 8:00：加えて今週ぶんの一覧

毎日の運用で大事なこと

PCがスリープしている間のメッセージは失われます

LINEは届かなかったメッセージを再送しません。スリープ中に送った「明日10時に歯医者」は、PCを起こしても登録されません（返事も来ないので、失敗したことは分かります）。

対策：スリープしないようにする

常用するなら、電源に繋いでいる間はスリープしない設定にしてください。

  1. Windowsキー + I で設定を開く
  2. 「システム」→「電源」（ノートPCは「電源とバッテリー」）
  3. 「画面とスリープ」 を開く
  4. 「電源接続時に、次の時間が経過した後にデバイスをスリープ状態にする」 → 「なし」

ノートPCの場合はさらに、「カバーを閉じたときの動作」を「何もしない」にする必要があります（コントロールパネル → ハードウェアとサウンド → 電源オプション → カバーを閉じたときの動作）。

それでも取りこぼしたら

返事が来なかったメッセージは、PCを起こしてからもう一度同じ文章を送り直せば登録されます。「返事が来たかどうか」が成功の目印です。

なお朝8時の通知は取りこぼしにくい作りです。スリープで8時を過ぎても、PCが起きたときにまとめて実行されます。

PCを再起動したあと

何もしなくて大丈夫です。Windowsにログインすると自動で立ち上がります。心配なら status.bat で確認してください。

困ったとき

まず status.bat

何かおかしいと思ったら、迷わず status.bat をダブルクリックしてください。設定・プロセス・通信・LINE側の設定・タスク登録を上から順に調べ、どこで止まっているかと、次に何をすべきかを表示します。

LINEに送っても何も返ってこない
  1. status.bat を実行して【失敗】の項目を見る
  2. 「Webhookサーバーが止まっています」→ 3_start.bat を実行
  3. 「Webhookの利用: オフ」→ LINE Official Account Manager → 設定 → 応答設定 → Webhook をオン
  4. すべてOKなのに返らない → PCがスリープしていた可能性。もう一度送ってみる
「⚠️ カレンダーに接続できません」と返ってくる

Googleの許可が切れています。返信に出ている手順（2_google_auth.bat をダブルクリック）をそのまま実行してください。それで直ります。

朝の通知でも同じことが起きると、LINEに同じ警告が1日1回届きます（黙って通知が止まらないようにするためです）。

繰り返し起きるなら STEP 2-3 の「本番環境」になっていない可能性が高いです。テストのままだと7日で切れます。

「エラーが発生しました」と返ってくる

プログラムは動いていますが、途中で失敗しています。C:\ai-hisho\logs\webhook.log をメモ帳で開き、いちばん下を見てください。

  • 429 / RESOURCE_EXHAUSTED → Geminiの無料枠を使い切っています。時間をおくか、課金設定を確認
  • 401 / Invalid access token → LINEのアクセストークンが違うか、再発行されています。1_setup.bat で入れ直す
変な予定が登録される・日付がずれる

AIの読み取り間違いです。もう少しはっきり書くと通ります（例：「明日」→「4/25」、「夕方」→「18時」）。

間違って登録されたものは ◯◯をキャンセル と送れば消せます。Googleカレンダーから直接消しても構いません。

朝8時に通知が来ない
  1. status.bat の「1. 設定ファイル」で LINE_USER_ID が設定済みか確認。空なら 4_set_user_id.bat
  2. 「6. 毎朝8時の通知」が「未登録」なら 3_start.bat
  3. その日の予定が0件なら、そもそも送りません（仕様）
  4. 「⚠️ カレンダーに接続できません」が届いていたら 2_google_auth.bat を実行
  5. test_notify.bat で今すぐ試して切り分ける
PCを再起動したら動かなくなった

status.bat で確認 → 止まっていれば 3_start.bat を実行。それで直ります。

毎回そうなる場合は、スタートアップ登録が消えている可能性があります。Windowsキー+R → shell:startup と入力してEnter → 「AI-Hisho Webhook」と「AI-Hisho Ngrok」のショートカットがあるか確認してください。無ければ 3_start.bat を実行し直します。

ngrokのURLが変わってしまった / 外から繋がらない

固定ドメインを使っているので、通常は変わりません。C:\ai-hisho\logs\ngrok.log の末尾を確認してください。

  • ERR_NGROK_108（同時接続数の上限）→ 別の場所でngrokが動いています。stop.bat のあと 3_start.bat
  • authentication failed → Authtokenが未設定。1_setup.bat をやり直す
  • unknown flag: --url → ngrokが古い版です。C:\ai-hisho\bin\ngrok.exe を削除して 1_setup.bat を実行すると入れ直されます
設定した鍵を入れ直したい

1_setup.bat をもう一度実行してください。今の値が表示され、Enter だけ押せばそのまま、入力すれば上書きされます。終わったら 3_start.bat で反映します。

それでも解決しないとき

次の2つを渡してもらえれば、たいてい原因が分かります。

  1. status.bat の画面をスクリーンショット
  2. C:\ai-hisho\logs\webhook.log の末尾30行ほど
送る前に確認

ログに鍵が写り込むことはまずありませんが、.env・credentials.json・token.json は絶対に送らないでください。これらはあなたのカレンダーとLINEを操作できる鍵そのものです。

やめたいとき

一時的に止める

stop.bat をダブルクリック。次にWindowsを起動するとまた立ち上がります。

自動起動をやめる

uninstall.bat をダブルクリック。自動起動と朝8時の通知が解除されます。設定ファイルは残るので、3_start.bat でいつでも戻せます。

完全に消す

  1. uninstall.bat を実行
  2. C:\ai-hisho フォルダをゴミ箱へ
  3. LINE Official Account Manager で公式アカウントを削除
  4. Google AI Studio で Gemini APIキーを削除
  5. Google Cloud で「AI秘書」プロジェクトを削除
  6. ngrok でドメインを削除
